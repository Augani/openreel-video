# Test fixtures

`speech-16k.wav` is 10 s of clean read speech (mono, 16 kHz, 16-bit) cut from the LibriVox recording of
"The Gettysburg Address" (archive.org item `gettysburg_address4_librivox`, file `lincoln_gettysburg_address_64kb.mp3`,
offset 12 s). LibriVox recordings are in the public domain (the item's licence URL is
http://creativecommons.org/licenses/publicdomain/). It is the clean reference for the objective SI-SDR tests; the
tests mix it with synthetic pink noise and a synthetic room impulse response.
