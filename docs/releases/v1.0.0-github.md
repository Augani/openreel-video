## OpenReel Desktop 1.0.0

First stable release of the desktop app for macOS (Apple Silicon and Intel), Windows and Linux. It follows `v1.0.0-alpha.17`.

**Download:** installers are at [dl.openreel.video](https://dl.openreel.video) (also linked from openreel.video). The app has a built-in updater (Linux: AppImage only; `.deb` users reinstall manually).

### Highlights

- **Editing:** edit-point trim (`,` `.`, numeric, ripple/roll), dynamic JKL trim, `Q`/`W` ripple trim to playhead, overwrite on timeline drag, gap select and delete.
- **Multicam:** audio/timecode/marker sync, live cutting with number keys, retimed multicam clips.
- **Effects and colour:** keyframes per effect instance with a per-parameter stopwatch, mask combine modes, effect presets, 27 new effects, an effect plugin SDK, scopes (RGB Parade, YC, HLS, false colour), 1D/3D LUT library with input LUT, pixel aspect ratio and field order.
- **Audio:** pitch-preserving speed changes, audible scrubbing, volume and pan automation lanes, 5.1 surround, loudness meter and normalise.
- **Titles and captions:** in-place title editing, roll/crawl, caption styles, saved styles, font embedding in project packages with licence checks.
- **Media:** ProRes, DNxHR and MXF without a proxy on desktop, proxy and ingest workflow, DNG and CinemaDNG (verified on synthetic files only).
- **Interchange:** XMEML, FCPXML, EDL (import with reel relink), OTIO and AAF.
- **Delivery:** export queue, smart render for H.264/HEVC, ProRes/DNxHR/XDCAM presets, image-sequence and GIF export, two-pass VBR, HDR10/HLG (several effects, masks and transitions still run on the 8-bit path in HDR projects).
- **Performance:** 4K scrub p95 about 900 ms to about 90 ms when the preview proxy is ready (30 s clip, macOS only; long clips scrub on the original until the proxy is built).
- **AI and agents:** first-run onboarding (AI, Learn, Pro paths) and a local MCP server that works without an editor window (`docs/MCP-SETUP.md`).

Full notes: [docs/releases/v1.0.0.md](docs/releases/v1.0.0.md).

### Known limitations

- Real-time collaboration is experimental and deferred (its end-to-end test fails).
- Interchange files were validated with independent tools but not opened in Premiere Pro, Resolve, Avid or Final Cut.
- Dynamic JKL trim does not preview the trimmed result live.
- Sequence pixel aspect applies to video only, not titles or graphics.
- WOFF2 fonts are not embedded in project packages.
- Wall-clock performance budgets were not judged on an idle machine. CPU and memory budgets pass.
- Layered 4K playback can peak at 3.7 to 4.0 GB in the worst case measured. That figure was not re-measured after the latest memory-governor changes. Tested only on a 16 GB Apple M2 Pro; 8 GB machines and Windows/Linux were not tested. 16 GB or more is recommended for 4K.
- Multicam: cuts inside ramped or frozen clips are refused, ramps and freezes are unit-tested only, and multicam is flattened in OTIO and EDL.
- RAW: the DNG decoder was verified on synthetic files only, and the browser RAW e2e was not run.
- Interlaced pro media (for example XDCAM HD422 1080i) is decoded as stored, with no deinterlacing.
- Windows and Linux were not performance-qualified; the Windows installer may show SmartScreen warnings if unsigned.

### Upgrading from the alpha

Install over the alpha. Existing projects open, and effect keyframes saved by effect type are rewritten onto effect instances on load. Keep a copy of important projects first, and do not open 1.0.0-saved projects in an alpha.
