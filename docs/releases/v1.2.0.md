# OpenReel 1.2.0 and Premiere editing workflows

An editor can synchronize a separate sound recording, assemble and trim a sequence, record narration, mix, grade, and export a shareable MP4 in the web app. The desktop app uses the same editor and adds native codecs, local scratch storage, native audio plug-ins and parallel segment encoding. The comparison below covers the workflows selected for 1.2. Adobe's documentation supplies the Premiere reference. The tests and measurements are from OpenReel.

## The eight workflows in the 1.2 plan

| Workflow | What an editor can do in OpenReel | Where to check the behavior |
| --- | --- | --- |
| Double-system sound | Synchronize timeline clips by waveform, In point or timecode. Merge camera and recorder assets from the Media panel. Undo restores the earlier edit. | [Waveform synchronization in Chrome](../../apps/web/e2e/sync-merge-clips.spec.ts) |
| Layer blending | Use Linear Burn, Darker Color, Lighter Color, Linear Light, Vivid Light, Pin Light, Hard Mix, Subtract, Divide and Dissolve in preview and export. | [Blend-mode pixel comparisons](../../apps/web/e2e/blend-modes-parity.spec.ts) |
| Loudness delivery | Select a delivery target, measure program or dialogue-gated loudness, check loudness range and true peak, and review the export result. | [Delivery specification tests](../../packages/core/src/audio/loudness/loudness-specs.test.ts) |
| Mixer automation | Record fader and pan moves in Write, Touch or Latch, play automation in Read, and automate rack parameters. | [OpenReel mixer tests](../../apps/web/e2e/audio-automation-modes.spec.ts) · [Premiere mixer modes](https://helpx.adobe.com/premiere/desktop/add-audio-effects/apply-audio-effects/audio-track-mixer-automation-modes.html) |
| Subject-aware reframing | Auto Reframe uses person segmentation to follow a subject and falls back when detection is unavailable. Inspect and adjust the resulting crop keyframes. | [Subject-tracking tests](../../apps/web/e2e/auto-reframe-subject.spec.ts) |
| Rendering while idle | Enable background rendering to fill the preview cache while a project is idle. It yields to editing, playback and export. Browser profiles default to a 1080p cache and opt-in idle rendering. Desktop defaults to full resolution and idle rendering on. Long native clips still use the original until the proxy is ready. | [Cache preferences](../../apps/web/src/services/render-cache-prefs.ts) · [Proxy measurements](../../apps/desktop/PERF.md) |
| Sequence assembly | Automate to Sequence assembles selected assets, including default transitions. Group clips to move them together or make a reusable subsequence. | [Five-asset assembly and grouping](../../apps/web/e2e/assembly-groups.spec.ts) |
| Creative audio and sidechain | Apply chorus, flanger, phaser, distortion, stereo width, polarity inversion and channel mapping. Key a compressor from another track using the built-in effects available on both platforms. Standalone rack pitch-shifting is outside this release. | [Audio effects and sidechain tests](../../apps/web/e2e/audio-creative-fx.spec.ts) |

## Editing, picture and delivery

- Search across source transcripts and use a word selection to mark and edit source footage. A two-up Trim Monitor shows both sides of a cut. Scene Edit Detection also recognizes fades and dissolves. [Source transcript tests](../../apps/web/e2e/source-transcripts.spec.ts) · [Trim and scene tests](../../apps/web/e2e/trim-monitor-scene-detect.spec.ts) · [Premiere text-based editing](https://helpx.adobe.com/premiere/desktop/edit-projects/edit-video-using-text-based-editing/edit-sequences-using-text-based-editing.html)
- Apply tracked masks to individual effects, stabilize footage, or use Remove Object on a tracked region. OpenReel uses classical segmentation and optical flow. The results depend on motion, contrast and the background available to reconstruct. [Object mask tests](../../apps/web/e2e/object-mask.spec.ts) · [Removal preview and export](../../apps/web/e2e/content-aware-fill.spec.ts) · [Premiere object masking](https://helpx.adobe.com/premiere/desktop/add-video-effects/work-with-masks/object-masking.html) · [Premiere Warp Stabilizer settings](https://helpx.adobe.com/premiere/desktop/add-video-effects/commonly-used-effects/warp-stabilizer-settings.html)
- Style individual characters in a title, use gradient fills and multiple strokes, apply lens correction, or grade on WebGPU. The browser checks the available GPU and codecs. Systems with a software GPU use the reference color renderer so selective corrections preserve colors outside the selected range. [Title styling](../../apps/web/e2e/rich-text-styling.spec.ts) · [Lens and Creative controls](../../apps/web/e2e/lumetri-creative-lens.spec.ts) · [GPU grading](../../apps/web/e2e/gpu-grade-chain.spec.ts)
- Open **Media → Record → Record voice-over**, choose a microphone, allow access and press **Record Voice Over**. The transport controls sit at the top of the panel. Retakes appear under **Media → Recordings**. Automated microphone inputs exercise recording, retakes, punch-in/out and device selection. [Voice-over tests](../../apps/web/e2e/voiceover.spec.ts)
- Choose the **Twitter** preset for an H.264 MP4 with stereo AAC-LC, including from a 5.1 sequence. The browser loads a software AAC encoder if needed. The regression downloads the actual file, inspects the stream headers and decodes its audio to verify a signal. The preset was also checked in Chrome, Firefox and WebKit. X account upload limits still apply. [Export verification](../../apps/web/e2e/social-audio-export.spec.ts) · [X media specifications](https://help.x.com/en/using-x/media-studio-faqs)
- Mark chapters on the timeline and enable **Chapters** in custom MP4 or MOV export. Chapter times in a ranged export are relative to the exported file. BWF audio delivery and mixer snapshots also work in the browser. [Chapter export tests](../../apps/web/e2e/export-queue.spec.ts) · [Mixer and BWF delivery](../../apps/web/e2e/mixer-submix-delivery.spec.ts)

## When desktop adds value

Use desktop for local AU or VST3 plug-ins, parallel native encodes, native ProRes or DNxHR masters, and broadcast formats such as MXF. HEVC Main10 PQ and HLG, measured PQ content light levels, and ProRes HDR are covered by real desktop exports. Browser codec support varies by device. Both editors share sequence settings, grading and the edit itself. [Native HDR verification](../../apps/desktop/test/hdr-export-electron.test.ts) · [Browser export checks](../../packages/core/src/export/browser-capabilities.ts)

Pipelined GPU readback is enabled for eligible native exports. The optional GPU colour conversion fell below the 45 dB comparison threshold on graded H.264 footage, so standard exports retain the reference colour conversion. Every decoded frame matched its reference on graded 1080p (450 frames) and 4K (360 frames) fixtures, in both serial and parallel modes. These are OpenReel-to-OpenReel measurements.
