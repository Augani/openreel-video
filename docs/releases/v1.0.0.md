# OpenReel Desktop 1.0.0

1.0.0 is the first stable release of the desktop app (macOS Apple Silicon and Intel, Windows, Linux). It follows `v1.0.0-alpha.17` and closes the release-blocking gaps found in the Premiere comparison audit (see `docs/PREMIERE-GAPS.md`), with a first-run experience and an MCP server for AI agents.

Not in 1.0: VST3/AU plugin hosting, Atmos and AC-3, `.prproj` import and Dynamic Link, `.mogrt`, ACES/OCIO, Dolby Vision, speaker diarization and translation, and watch folders.

Download from [dl.openreel.video](https://dl.openreel.video) (also linked from openreel.video). The app updates itself from the same location.

This page says what was built and what was verified. Where something has not been checked, it is listed under [Known limitations](#known-limitations), not described as working.

## Editing and trimming

- **Edit-point trimming.** Select an edit point or a gap, trim with `,` and `.` (Shift moves 5 frames), type a numeric trim, and toggle ripple or roll. Mark Clip, Go to In/Out and gap delete are included. `Q` and `W` ripple-trim the previous or next edit to the playhead, honour locked and untargeted tracks, and account for speed and reverse.
- **Dynamic JKL trim.** With an edit point selected, `J`/`L` play and the edit point follows. `K` commits the trim as one undo step and `Esc` cancels. The trimmed result is not previewed live while you do this (see limitations).
- **Timeline drags resolve overlaps.** Dropping a clip onto another overwrites by default instead of leaving overlapping clips, and a failed drop is reverted.
- **Pro edit tools.** Source monitor with three-point insert/overwrite, lift and extract, rolling edit, slide, slip, rate stretch, Track Select, Hand and Zoom tools, sync lock, track targeting and source patching, J/L split edits and Extend Edit.
- **Project panel.** Bins, labels, list view, subclips, smart bins and search.
- **Markers.** Range markers with comments and kinds, a Markers panel, marker navigation, and export to chapters, CSV and EDL.
- **Sequences.** Multiple sequences per project and nested sequences that open as their own timelines. Dockable workspaces can be saved, and project files are locked so a second instance opens them read-only.
- **Project versions and review comments**, and Save As.

## Multicam

- Create a multicam source from 2 to 9 clips, synced by audio waveform, timecode, In points or markers. Cut live with the number keys and the whole pass is one undo step. Switch an angle after the fact, or flatten.
- Multicam clips can be retimed (constant speed and reverse) and keep picture and audio locked. Fixed audio angles stay sample-locked under edits.
- Cuts and live recording inside a multicam clip that has a speed ramp or freeze frame are refused; cut first, then add the ramp, or switch the whole clip's angle. Ramps and freeze frames on multicam clips are verified by unit tests only (no e2e or export check).

## Effects and colour

- **Effect keyframes belong to the effect instance.** Two copies of the same effect animate independently, every effect parameter has a stopwatch, and the keyframe graph editor has Bezier handles, a speed graph and ease presets. Older projects are converted on load (see [Upgrading](#upgrading-from-the-alpha)).
- **Masks** have combine modes (add, subtract, intersect, difference), and there is a mask pen tool on the Program monitor.
- **Effect presets** can be saved, imported and applied from a preset panel.
- **Effects library.** 27 added video effects with matching shader and CPU paths, plus a sandboxed effect plugin SDK with a plugin manager (see `docs/plugin-sdk.md`).
- **Lumetri-style grading** in Premiere order: Basic Correction, vignette, Auto Tone, Match Color, colour wheels, hue curves, curves, HSL secondary, and a comparison view.
- **Scopes** at 512 px with RGB Parade, YC and HLS modes, false colour and a nit scale.
- **LUTs.** The `.cube` parser reads 1D and 3D tables with their domain and validates strictly. There is a LUT library, an input LUT slot, `.cube` export and saved looks. Float LUT data is kept on the GPU and HDR paths, with a CPU fallback.
- **Working colour space and HDR.** Rec.709 or Rec.2020 working space. On desktop, 10-bit HDR10 (PQ) and HLG export, with a scene-referred half-float working mode (see `docs/colour-management.md`).
- **Pixel aspect ratio and field order.** Interpret Footage sets frame rate, pixel aspect and field order on footage. They are applied in preview, thumbnails and export, with deinterlacing.

## Audio

- Pitch-preserving speed changes (Maintain Pitch), stretched off the main thread and cached.
- Audible scrubbing, with a timeline toggle.
- Track volume and pan automation lanes, and clip pan automation, rendered in preview and export.
- On-timeline clip gain rubber band, with pen-click keyframes.
- Mixer with buses, sends, per-track and master effect racks, plugin delay compensation, gain-reduction meters, a lookahead brickwall limiter and low-pass filter, and live dialogue ducking.
- Essential Sound panel (Dialogue, Music, SFX, Ambience) with loudness matching.
- BS.1770-4 / EBU R128 loudness meter, clip normalise and loudness-targeted export.
- 5.1 surround sequences with a surround panner, six-channel export and stem export.
- Audio repair tools: analysis, spectrogram and a repair panel.

## Titles and captions

- Edit titles in place on the canvas.
- Roll and crawl titles.
- Caption style model (stroke, shadow, position) with WebVTT cue settings. Styles for titles and captions can be saved and reused.
- Transcript panel with transcript-based editing, caption QC, per-track burn-in, embedded CEA-608 captions, and SCC and EBU-STL import and export.
- Graphic templates with exposed controls (`.openreel-template`), and live linked compositions with render-and-replace (`docs/linked-compositions.md`).
- Path shapes from SVG path data render in preview and export.
- A missing-font report appears when a project or template is opened. Project packages embed fonts whose licence permits it and report the status of the rest.

## Media, proxies and RAW

- **ProRes, DNxHD/HR, XDCAM and MXF** decode through the bundled ffmpeg on desktop with no proxy needed (`docs/pro-media.md`). On the web build these use a proxy.
- **Proxy and ingest workflow.** Native proxy queue, copy-to-project ingest, Toggle Proxies, attach and relink, and folder-search relink. A 4K original that the decoder refuses gets a proxy requested automatically.
- **Camera RAW.** DNG stills and CinemaDNG sequences import with RAW Source Settings (white balance, exposure, highlight recovery, demosaic quality, output colour space). Vendor RAW formats import on macOS through Apple ImageIO only (`docs/raw.md`).
- **Memory governor.** Preview quality is reduced under memory pressure instead of letting caches grow, and a "Memory high" badge says so.

## Interchange

Export and import timelines from File > Export timeline and File > Import timeline: XMEML (Premiere and Resolve XML), FCPXML 1.10, CMX3600 EDL, OpenTimelineIO and AAF. Nested sequences round-trip through XMEML, OTIO and FCPXML, and multicam cuts are written as XMEML multiclips. EDL import reads reel names and relinks by reel and timecode. Every export produces a report of what the format could not carry. See `docs/interchange.md`.

These files have been checked against independent libraries and validators. They have not been opened in Premiere Pro, DaVinci Resolve, Avid or Final Cut. Treat interchange as unverified in those hosts.

## Export and delivery

- Export queue with isolated engines, ETA, pause, retry and reorder, persisted across restarts (`docs/export-queue.md`).
- Smart render for H.264 and HEVC: untouched, grid-aligned spans are stream-copied and the rest is re-encoded.
- ProRes (including 4444 with alpha), DNxHR, XDCAM HD422 and AVC-Intra delivery presets on desktop.
- Image-sequence and GIF export in the Export dialog.
- Target and maximum bitrate, and two-pass VBR on the desktop encoder. Two-pass is not offered for AV1 or fixed-rate codecs, or for Rec.2020 projects.
- Custom export presets can be saved, imported, exported and managed.
- A preview render cache ("Render In to Out") is reused in export.

## Performance

Measured on an Apple M2 Pro (12 cores, 16 GB), on a machine that was not idle (details in `apps/desktop/PERF.md`):

- 4K scrub latency p95 about 900 ms before, about 90 ms after, because the preview proxy is ready before the first scrub (macOS builds the proxy with software decode, which is faster than hardware decode for that job). This was measured on macOS only, with a 30 s clip and the bundled ffmpeg; other platforms were not measured, and a long 4K clip still scrubs on the original until its proxy is built.
- Budgets for scrub, playback and import are defined; the CPU and memory ones pass. The wall-clock ones are provisional and have not yet been run on an idle machine. A dropped-frame indicator shows in the editor.

All CPU and memory budgets pass. The wall-clock budgets were not judged on an idle machine, so the figures above are not a guarantee on your hardware.

## Onboarding and AI agents

- **First-run onboarding** offers AI, Learn and Pro paths. The Learn path has a practice project, a Lesson Bar and a Lesson Hub. The AI path supports bring-your-own key and a local Ollama model. The Pro path sets a sequence preset and workspace.
- **MCP server.** The desktop app runs a local MCP server (loopback only, bearer token) that any MCP client can use to create projects, import media, edit and export. It works with no editor window open. Setup is in `docs/MCP-SETUP.md`, and Settings > MCP has copy-ready snippets.
- About 450 agent tools sit on the same undoable actions as the UI (`docs/AGENT-CAPABILITIES.md`), including tools for interpret footage, trim, effect instances, presets, scopes, image-sequence and GIF export, and font status.

## Known limitations

Full detail is in `docs/known-limitations.md` and `docs/PREMIERE-GAPS.md`.

- **Real-time collaboration is experimental and deferred.** Its end-to-end test fails and it has not been deployed. Do not rely on it for real work.
- **Interchange is unverified in Premiere Pro, Resolve, Avid and Final Cut.** XMEML, FCPXML, EDL and AAF were validated with independent tools only.
- **Dynamic JKL trim has no live preview** of the trimmed result while you trim.
- **Sequence pixel aspect applies to video only,** not titles or graphics.
- **WOFF2 fonts are not embedded** in project packages.
- **Performance was not judged on an idle machine** for wall-clock budgets. 4K scrub p95 was about 90 to 100 ms, with under 1% dropped frames, but on a loaded machine.
- **Layered 4K playback can still peak at 3.7 to 4.0 GB** in the worst case measured (two overlapping 4K layers from whole 10-minute sources). That figure predates the latest memory-governor changes and was not re-measured. Tested only on a 16 GB Apple M2 Pro; 8 GB machines and Windows/Linux were not tested. 16 GB or more is recommended for 4K.
- **HDR:** the browser build has no HDR sources. Several effects, masks and transitions still run on the 8-bit path in HDR projects (`docs/known-limitations.md`).
- **RAW:** BRAW, R3D and ARRIRAW are not supported. The DNG decoder was verified on synthetic files only, and the browser RAW end-to-end spec has not been run.
- **Multicam:** cuts inside ramped or frozen clips are refused; ramps and freezes are unit-tested only; multicam is flattened in OTIO and EDL; FCPXML import keeps only the selected angle.
- **Interlaced pro media** (for example XDCAM HD422 1080i) is decoded as stored, with no deinterlacing in preview or export (`docs/pro-media.md`).
- **Windows and Linux** builds are produced by the release workflow, but performance was qualified on macOS only. The Windows installer may show SmartScreen warnings if it is not code-signed. Linux auto-update works for the AppImage only; `.deb` users must reinstall manually.

## Upgrading from the alpha

- Existing projects open in 1.0.0. Effect keyframes saved against an effect type (for example `effect.brightness`) are rewritten onto the effect instance when a project loads. The rewrite is idempotent. Keep a copy of important projects before opening them in 1.0.0, as you would before any upgrade. Do not open a project saved in 1.0.0 in an alpha: its effect keyframes will probably not animate correctly there.
- Colour grades that already exist keep the classic processing order. Only a clip's first new grade uses the Premiere order, and the Color tab can switch it.
- Clips saved without a text style get the default style, and media items saved without metadata are tolerated when reading interpretation settings.
- Install 1.0.0 over the alpha from the download page. The app also has a built-in updater, which alpha installs are expected to use to receive 1.0.0; this has not been confirmed end to end until the release workflow has published the update feed.
